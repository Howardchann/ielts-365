# 雅思365 · 微信小程序版

零基础雅思全年学习计划（4 阶段 / 52 周 / 364 天 / 1300 词），由 H5 版完整迁移。
语音朗读使用微信官方**同声传译插件**（免域名、免服务器）；进度通过**云开发**在手机与电脑间自动同步。

## 一、项目结构

```
ielts-miniprogram/
├── project.config.json        # 工具配置（需替换 appid）
└── miniprogram/
    ├── app.js                  # 云开发初始化
    ├── app.json                # 页面注册 / tabBar / 插件声明
    ├── app.wxss                # 全局样式
    ├── sitemap.json
    ├── images/                 # tabBar 图标
    ├── utils/
    │   ├── data.js             # 52 周数据汇总 + 天数计算
    │   ├── data-p1~p4.js       # 四阶段课程数据（由 H5 版提取）
    │   ├── speech.js           # 语音引擎（插件 TTS + 在线兜底 + 连读队列）
    │   └── store.js            # 进度管理（本地缓存 + 云同步，防抖 3 秒）
    └── pages/
        ├── today/              # 今日计划：打卡、词汇、语法、练习、提示
        ├── weeks/              # 52 周总览：四阶段、每周进度条、点日期直达
        ├── review/             # 复习：随机抽查（30% 优先重点词）、重点词列表
        └── settings/           # 设置：开始日期、语速、引擎、云同步
```

## 二、部署步骤（约 15 分钟）

### 1. 注册小程序（免费，个人主体即可）
- 访问 https://mp.weixin.qq.com → 立即注册 → 小程序
- 注册后在「设置 → 基本设置」查看 **AppID**

### 2. 下载微信开发者工具
- https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- 安装后登录你的微信

### 3. 导入项目
- 解压本 ZIP
- 开发者工具 → 导入项目 → 目录选 `ielts-miniprogram`（含 project.config.json 的目录）
- AppID 填你自己的（或用"测试号"先本地体验，但无法用云开发）
- 把 `project.config.json` 中 `"appid": "请替换为你的AppID"` 改为你的 AppID

### 4. 添加同声传译插件（语音必需）
- 登录 mp.weixin.qq.com → 设置 → 第三方设置 → 插件管理 → 添加插件
- 搜索「**同声传译**」（提供方：微信，AppID `wx069ba97219f66d99`）→ 添加
- 回到开发者工具重新编译，设置页应显示「插件已就绪」

### 5. 开通云开发（进度同步必需）
- 开发者工具顶部点「云开发」→ 开通（环境名随意，如 ielts-365）
- 基础版有免费额度，个人使用完全够
- 在云开发控制台 → 数据库 → 创建集合 **`progress`**
- 集合权限：改为「**仅创建者可读写**」（默认即是）

### 6. 预览与发布
- 开发者工具点「预览」→ 手机扫码即可在微信里使用（语音、云同步全功能可用）
- 满意后点「上传」→ mp.weixin.qq.com 提交审核
- 类目建议：**工具 → 效率**（个人主体可选）
- 首次审核一般 1~7 天

## 三、多端同步原理

- 手机和电脑（开发者工具也算一个"端"）登录**同一微信**，云数据库按 openid 自动隔离用户
- 写入：先落本地（即时生效），防抖 3 秒后推云端
- 读取：启动、切回前台时从云端拉取较新版本（updatedAt 较大者胜）
- 典型双端用法：电脑上用开发者工具的「自动预览/真机调试」窗口操作，手机用正式小程序，切回前台即自动对齐

## 四、语音方案说明

| 引擎 | 依赖 | 效果 |
|---|---|---|
| 同声传译插件（默认） | 后台添加插件 | 微信官方 TTS，英文发音稳定，无需域名 |
| 在线朗读（自动兜底/可选） | 后台配置 downloadFile 合法域名 `dict.youdao.com` | 插件不可用时的备用通道 |

- 语速 0.70~1.30×（通过 InnerAudioContext.playbackRate 实现），默认 0.90×
- 支持单词/例句朗读、整日连读、暂停/恢复
- 真机上如果默认引擎无声：设置 → 朗读引擎 → 切换测试

## 五、注意事项

1. **H5 进度不会自动迁移**：H5 存在浏览器 localStorage，小程序存在微信 Storage + 云数据库，两边独立。若 H5 已有进度，在小程序「设置 → 计划开始日期」里调整日期对齐，或直接重新开始（364 天计划重新走一遍也无妨）
2. **语音无 sound 排查**：① 设置页看插件是否就绪 ② 真机静音键 ③ 切换引擎试听
3. **云同步不生效排查**：① 是否开通云开发 ② `progress` 集合是否创建 ③ 权限是否「仅创建者可读写」
4. **审核被拒常见原因**：类目不匹配（用工具-效率）、页面出现外链二维码等；本小程序无支付无外链，一般无碍
5. **代码包大小**：约 340KB（含全部课程数据），远低于 2MB 限制，无需分包
6. **更新课程数据**：改 `utils/data-p*.js` 后重新上传发布即可

## 六、与 H5 版的功能对照

| 功能 | H5 | 小程序 |
|---|---|---|
| 52 周课程/打卡/重点词 | ✓ | ✓ |
| 语音朗读 | SpeechSynthesis + 在线 TTS 混合（兼容性差） | 同声传译插件（官方，稳定） |
| 多端进度同步 | 无（localStorage 单机） | ✓ 云数据库自动同步 |
| 离线使用 | PWA 缓存（部分支持） | 无离线（需网络） |
| 添加到桌面 | PWA（安卓可） | 微信内固定入口，更方便 |
