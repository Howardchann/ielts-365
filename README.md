# 雅思365 · 微信小程序版

零基础雅思全年学习计划（4 阶段 / 52 周 / 364 天 / 1300 词），由 H5 版完整迁移。

> **当前版本面向「个人主体」小程序**
> - **语音**：使用有道在线 TTS，需要在小程序后台把 `dict.youdao.com` 加入 downloadFile 合法域名。
> - **为什么不用微信官方同声传译插件**：① 个人主体在后台搜不到该插件；② 它有 **50 字符**上限，本项目有 127 条语法例句超出，插件读不了。
> - **进度**：默认仅本地存储，**建议定期用设置页的「进度备份」导出保存**（见第 6 节）。
> - 完整改动与决策记录见 [CHANGELOG.md](./CHANGELOG.md)；**给 AI / 新接手者看的决策背景见 [AI-CONTEXT.md](./AI-CONTEXT.md)**。

## 一、项目结构

```
ielts-miniprogram/
├── project.config.json        # 工具配置（需替换 appid）
└── miniprogram/
    ├── app.js                  # 云开发初始化
    ├── app.json                # 页面注册 / tabBar / 插件声明
    ├── app.wxss                # 全局样式
    ├── sitemap.json
    ├── images/                 # tabBar 图标
    ├── utils/
    │   ├── data.js             # 52 周数据汇总 + 天数计算
    │   ├── data-p1~p4.js       # 四阶段课程数据（由 H5 版提取）
    │   ├── speech.js           # 语音引擎（插件 TTS + 在线兜底 + 连读队列）
    │   └── store.js            # 进度管理（本地缓存 + 云同步，防抖 3 秒）
    └── pages/
        ├── today/              # 今日计划：打卡、词汇、语法、练习、提示
        ├── weeks/              # 52 周总览：四阶段、每周进度条、点日期直达
        ├── review/             # 复习：随机抽查（30% 优先重点词）、重点词列表
        └── settings/           # 设置：开始日期、语速、引擎、云同步
```

## 二、部署步骤（约 15 分钟）

### 1. 注册小程序（免费，个人主体即可）
- 访问 https://mp.weixin.qq.com → 立即注册 → 小程序
- 注册后在「设置 → 基本设置」查看 **AppID**

### 2. 下载微信开发者工具
- https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- 安装后登录你的微信

### 3. 导入项目
- 解压本 ZIP
- 开发者工具 → 导入项目 → 目录选 `ielts-miniprogram`（含 project.config.json 的目录）
- AppID 填你自己的（或用"测试号"先本地体验，但无法用云开发）
- 把 `project.config.json` 中 `"appid": "请替换为你的AppID"` 改为你的 AppID

### 4. 配置语音域名（必须，否则所有朗读无声）

- 登录 mp.weixin.qq.com → 开发管理 → 开发设置 → **服务器域名**
- 在 **downloadFile 合法域名** 中添加：`https://dict.youdao.com`
- 添加了域名后需重新编译；每月可修改的次数有限，一次填对

> **关于微信同声传译插件**（AppID `wx069ba97219f66d99`）：添加路径是「设置 → 第三方设置 → 插件管理 → 添加插件」，但**个人主体搜不到它**（社区答复："个人不支持，因为这个插件的类目个人主体没有"）。
>
> 即使是企业/个体户主体能用，也**不建议**——它有 50 字符上限，本项目 127 条语法例句（最长 222 字符）它读不了；代码里这部分会自动转在线通道，等于插件只承担一半工作还多一套配置。
>
> 主体相关的完整结论见 [CHANGELOG.md](./CHANGELOG.md) 末尾。

### 5. 开通云开发（**可选**，想清楚了再开）

进度默认存在本机（`wx.setStorageSync`），**不开云开发也能正常使用**，只是不能多端同步。

如果确实需要手机和电脑自动对齐：

- 开发者工具顶部点「云开发」→ 开通（环境名随意）
- 云开发控制台 → 数据库 → 创建集合 **`progress`**
- 集合权限改为「**仅创建者可读写**」

> ⚠️ **发布后第 15 天会失效**：按微信官方计费文档，**免费体验环境在小程序发布后，到期时间变更为上线后的第 15 天**，之后需转为付费环境才能继续（个人版约 19.9 元/月）。
>
> 到期后**小程序不会崩溃**——`store.js` 会降级为纯本地存储，已有进度不丢，只是不再同步。但要注意：此时你的学习记录仍然**只有本地一份**，卸载微信或换手机就会全部消失。
>
> 更省钱的替代方案：在设置页做「导出备份 / 导入恢复」，把进度存成文本保管（此功能尚未实现，见 CHANGELOG 遗留问题第 2 条）。

### 6. 预览与发布
- 开发者工具点「预览」→ 手机扫码即可在微信里使用（语音、云同步全功能可用）
- 满意后点「上传」→ mp.weixin.qq.com 提交审核
- 类目建议：**工具 → 效率**（个人主体可选）
- 首次审核一般 1~7 天

## 三、进度存储与备份

### 默认：存在本机

进度写入 `wx.setStorageSync`。**不开云开发完全能用**，但换手机、卸载微信、清缓存会全部丢失。

### 备份（推荐做法）

设置页 → **进度备份**：

| 操作 | 说明 |
|---|---|
| **导出备份** | 生成一段 JSON，自动复制到剪贴板。粘贴到「文件传输助手」或备忘录保存 |
| **合并导入**（推荐） | 保留现有进度，补上备份里缺的部分。手机和电脑各自学完再互导，等于人工同步 |
| **覆盖导入** | 以备份为准替换，本机现有进度会被清除 |

建议每月导出一次，成本几乎为零。

### 云同步（可选）

开通云开发后会自动在手机与电脑间同步，数据库按 openid 隔离用户：

- 控制台 → 数据库 → 创建集合 **`progress`**，权限设为「**仅创建者可读写**」
- 写入先落本地（即时生效），防抖 3 秒后推云端；启动与切回前台时拉取较新版本（`updatedAt` 大者胜）
- 设置页会直接显示云端返回的具体错误，修复后点「立即同步」强制重试，无需重启

> ⚠️ **发布后第 15 天会失效**（微信官方计费文档：免费体验环境的到期时间变更为上线后的第 15 天）。到期不会崩溃，会静默降级为本地存储，已有进度不丢，只是不再同步。

## 四、语音方案说明

| 引擎 | 依赖 | 说明 |
|---|---|---|
| **在线朗读（当前默认）** | downloadFile 合法域名 `dict.youdao.com` | 无 50 字符限制，支持美式/英式；免费但属非官方接口，无 SLA |
| 同声传译插件 | 后台添加插件 + `app.json` 声明 | 官方 TTS；**50 字符上限**、配额 100 次/分 · 2w 次/天、仅美式。**个人主体搜不到**，本版已移除声明 |

- 语速 0.70~1.30×（通过 InnerAudioContext.playbackRate 实现），默认 0.90×
- 发音口音：设置页可选美式/英式，**仅在线朗读通道生效**（插件通道官方只有 en_US 一种发音）；切换后点「试听发音」对比
- 支持单词/例句朗读、整日连读、暂停/恢复；连读中点任意单词会自动打断连读
- 播放前已调用 `wx.setInnerAudioOption({ obeyMuteSwitch: false })`，iPhone 静音键打开时也能出声
- 已经按官方回调规范处理：`retcode === 0` 才算合成成功，`-20003/-20005/-40001` 等错误码会翻译成可读提示
- 同一句话 3 小时内复用缓存的合成文件，重复朗读不再消耗插件调用配额
- 阶段四的作文范文例句最长达 222 字符（共 127 条超 50 字符），在线通道可直接朗读，不受限制
- **真机无声的排查顺序**：① 后台是否把 `dict.youdao.com` 加进 downloadFile 合法域名（最常见）② 设置 → 朗读引擎 → 切换测试 ③ 设置页点「试听发音」

## 五、注意事项

1. **H5 进度不会自动迁移**：H5 存在浏览器 localStorage，小程序存在微信 Storage + 云数据库，两边独立。若 H5 已有进度，在小程序「设置 → 计划开始日期」里调整日期对齐，或直接重新开始（364 天计划重新走一遍也无妨）
2. **语音无声排查**：① 设置页看插件是否就绪 ② 切换引擎试听 ③ 切换到「仅在线朗读」验证域名是否配置（iPhone 静音键已由代码规避，无需自行检查）
3. **云同步不生效排查**：① 是否开通云开发 ② `progress` 集合是否创建 ③ 权限是否「仅创建者可读写」④ **是否已上线超过 15 天**（免费环境到期）。设置页会直接显示云端返回的具体错误（如"未找到 progress 集合"），按提示处理即可；修复后点「立即同步」强制重试，无需重启小程序
4. **已知显示问题**：未开通云开发时，设置页会显示「尚未建立云端记录（打开几天后会自动创建）」——这是不准确的表述，实际不会自动创建。对应 `store.js:257` 的判断逻辑，不影响使用，待修
5. **审核被拒常见原因**：类目不匹配（建议 工具 → 效率）、页面出现外链二维码等；本小程序无支付无外链，一般无碍
6. **代码包大小**：约 340KB（含全部课程数据），远低于 2MB 限制，无需分包
7. **备份你的进度**：进度存在本机 Storage，卸载微信或换手机会全部丢失。建议定期在设置页或使用云同步保底

## 六、与 H5 版的功能对照

| 功能 | H5 | 小程序 |
|---|---|---|
| 52 周课程/打卡/重点词 | ✓ | ✓ |
| 语音朗读 | SpeechSynthesis + 在线 TTS 混合（兼容性差） | 有道在线 TTS（已处理 iOS 静音键、防叠音、缓存） |
| 多端进度同步 | 无（localStorage 单机） | 可选，需开通云开发；**免费环境在上线第 15 天到期** |
| 离线使用 | PWA 缓存（部分支持） | 无离线（需网络） |
| 添加到桌面 | PWA（安卓可） | 微信内固定入口，更方便 |
