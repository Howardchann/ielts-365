1标点与排版规范（6 条，适用全应用）

你指出的"句号该不该用、该不该用破折号"，我定为以下规则，后续所有文字按此执行：
R1 句末
UI 独立说明句（设置页灰色说明、空态、预备期提示）句末一律不加句号例："跟随系统时，切到夜间会自动换成深色，无需手动操作" —— 界面短说明不是文章，去句号更轻。
R2 破折号
"总起判断 → 由此展开"的衔接用 ——，不硬切两句；空态句的"现状——怎么办"同样用破折号例："零基础最大的敌人是不敢开口——从今天起……"；"暂无到期词汇——学过的词到复习周期后会自动出现在这里"。不滥用：并列事实仍用句号/分号。
R3 空格
阿拉伯数字、英文与中文之间加半角空格"至少15分钟"→"至少 15 分钟"；"用今天的{D}个新词"→"{D} 个新词"（第 3 周起的新文案已是此风格，第 1-2 周旧文案全量补齐）。
R4 引号
统一用直角引号「」，替换现存的弯引号 " "例："持续在场"→「持续在场」。与第 3 周起文案的既有风格对齐。
R5 成段
教学成段文字（学习提示 / 目标 / 语法讲解 / 自检）保留句号——成段阅读需要句读；弹窗长文案同此所以不是"把句号全删"，而是"短说明去句号、成段保留"。
R6 轻反馈
toast / 按钮 / 状态行：无句末标点，≤12 字优先"已复制""导出失败""同步中…"维持现状。
