按钮图标对齐 · 根因实锤 + 统一方案

你观察到的"两个停止按钮一个偏下一个正常"——不是错觉，是 同一个 .ico 类走了两套对齐机制。本页 1:1 复刻线上 CSS 并实测词墨中心线。

根因：两套对齐机制并存机制分裂

竖直方向上图标怎么摆，取决于按钮的 display：flex 容器里 vertical-align 失效，走 align-items:center（对齐"行盒中心"）；inline-block 里 vertical-align:-8rpx 生效（对齐"基线-4px"，这数字是按 30rpx 字调的）。设置页试听按钮恰好把 display 覆盖成了 inline-block。
实测 A · 设置页「停止试听」btn-voice（display:inline-block → 基线魔法数 -4px，按 15px 字调的，13.5px 字下偏）
实测 B · 今日页「停止朗读」btn-speak-all（display:inline-flex → flex 居中）
词墨中心（文字墨水上下沿中点，canvas 实测） 图标中心
偏移数字标注在每行右侧（图标中心 − 词墨中心，正=偏下）。线上机制不同 → 两个按钮一个正一个偏，且固定 15px 图标配 13.5px 字本身还有 1.5px 超差。

统一方案预览（1em 图标 + 全部 flex 居中）预测偏差 ≤0.5px

改法：① .ico 尺寸改 1em（图标=所在按钮字号，27rpx 按钮自动 13.5px，done-state 自动 14px）；② .btn-voice 去掉 display:inline-block 覆盖（恢复 flex）。flex 居中 = 行盒中心，而 CJK 词墨中心 ≈ 行盒中心（中文字形在字身框里上下基本对称，偏差 <0.5px）——即天然满足你的"词墨上下沿中点"标准，不再需要任何魔法数。下方为改后 1:1 预览：
